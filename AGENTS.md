## Agent skills

### Issue tracker

Issues and specs live in GitHub Issues via `gh`. See `docs/agents/issue-tracker.md`.

### Triage labels

Use `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, and `wontfix`. See `docs/agents/triage-labels.md`.

### Issue-kind labels

Classify specs and implementation subtasks with the `spec` and `subtask` labels. See `docs/agents/issue-tracker.md`.

### Domain docs

This is a single-context repo; use the root `GLOSSARY.md` and `docs/adr/`. See `docs/agents/domain.md`.
